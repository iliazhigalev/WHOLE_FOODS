# WHOLE FOODS Backend

Это backend-проект на Python с использованием FastAPI. Проект настроен с современными инструментами разработки, проверки качества кода и виртуальным окружением через `uv`.

## Стек технологий

- **Python 3.13.9** — основной язык разработки
- **FastAPI** — фреймворк для создания REST API
- **Uvicorn** — ASGI-сервер для запуска FastAPI
- **Virtual environment** через `uv` для управления зависимостями

## Инструменты для разработки и качества кода

- **Mypy** — статическая проверка типов Python
- **Ruff** — линтер и автоформатирование кода
- **Bandit** — проверка безопасности Python-кода
- **Radon** — анализ сложности кода
- **Pre-commit** — автоматический запуск проверок перед коммитом
- **Loguru** — продвинутое логирование (опционально)
